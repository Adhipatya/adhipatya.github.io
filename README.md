# Adhipatya Sonbhadra — Portfolio

A clean, minimal UX/product design portfolio. Static site (HTML/CSS/JS), no build step.

## Pages
- `index.html` — landing page (work, tools, skills, about, contact)
- `case-schindler.html` — Schindler One case study
- `case-ai-companion.html` — AI Companion case study
- `case-biotopic.html` — Biotopic case study
- `case-devpuja.html` — DevPuja case study
- `case-blisslife.html` — BlissLife case study
- `contact.html` — contact page
- `images/` — all project imagery

## Run locally
Just open `index.html` in a browser, or serve the folder:
```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploy
Hosted with GitHub Pages. Any push to the `main` branch publishes automatically.
